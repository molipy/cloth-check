# cloth-check
基于YOLO的布匹检测系统~2026原创+计算机毕设项目

## 一、介绍
基于YOLO的布匹缺陷检测系统，技术栈如下：
● 前端：Vue3+Element plus
● 后端：Flask框架
● 算法：YOLO
关键技术：YOLO模型、模型训练、目标检测、人工智能、Python
